# 界面精简、操作历史与生图能力核查

本轮按用户最新要求完成小范围修改和定向验证，没有进行全仓审计、全量测试、发行或线上部署。基线为 `bce674a35010bf2a2d9243f9501874c3e581e92a`；[证据索引](../audit-evidence/ui-history-20261102/verification.json)记录修改文件、构建、截图与测试结果的 SHA-256。

## 界面与历史行为

- ROOT 位于顶部右侧、连接状态左侧，保持单行；移除侧栏“最近会话”标题，排序和刷新按钮同排。
- “操作记录”按创建时间倒序显示成功、失败、已关闭提醒和已停止本地恢复的记录。移除逐条“已知悉”以及批量清理确认控件，不新增人工知悉标记。
- 自动保留最近 **500 条已退出恢复的历史**；活动恢复记录独立保留，常规上限 200，另有一条紧急恢复预留。历史不占用执行准入预算，不重新触发查询、执行或恢复。
- 退出活动恢复表与保存脱敏历史在同一事务完成。待确认操作、未加载目标的会话回执、终端所有权及紧急恢复凭证仍受保护；旧版草稿不会因为历史归档而被删除。
- 失败后的新尝试使用新操作 ID，旧失败与新结果分别保留。不会仅凭相同操作范围推断用户已处理旧错误，也不会自动重发。旧版本已经删除的本地记录无法补回。
- 损坏的纯展示历史与已关闭的旧版坏快照不会锁住合法活动恢复；活动记录校验、数据库提交失败和未知结果保护保持严格。

独立复核发现：删除人工清理入口后，部分“先未知、后查询成功”的普通操作及旧版会话回执缺少容量退出路径。现已补齐压力回收和实际加载后的消费路径；查询成功时不会立即删除调用方尚需读取的回执。新增回归覆盖 240 次查询成功、200 条旧版普通回执、旧会话加载后保留草稿，以及终端/紧急恢复的容量保护。[原发现](../audit-evidence/ui-history-20261102/ui-operation-history-initial-finding.json)与[最终独审](../audit-evidence/ui-history-20261102/ui-operation-history-independent.json)分别保留，最终无未解决发现。

## ChatGPT 生图核查

当前固定的 Codex CLI **0.164.0** 会向符合 OpenAI 认证条件的会话提供原生生图工具；托管 ChatGPT 供应商满足该条件。标准 app-server 使用内联图片存储，正常成功结果通过 `imageGeneration.result` 返回 Base64，项目现有事件、历史、图片预览与下载路径能够消费。可在 ChatGPT 模型会话中用自然语言提出生图要求，由模型决定调用工具。

本轮修复了生成中/失败时误显示“只有文件 ID”的提示，并验证从等待状态转为图片预览、下载的离线流程。另移除了会话设置中的全局供应商能力查询及误导说明：该原生接口读取的是全局默认供应商，不能代表当前会话模型或账号。

**尚未进行真实账号生图验收。** 当前账号额度、模型是否调用工具、实际网络与上游成功率均未验证。现有 4 MiB WebSocket 消息预算及 4,000,000 字符历史预算仍可能限制大图或多图；仅有文件 ID 的结果没有独立取回通道，原生 HOME 下保存路径也不能直接充当项目文件下载路径。因此结论是正常默认内联链路已接通，不能称所有生图场景都已验证可用。

详细来源、固定官方 Git blob 与边界见[能力核查报告](../audit-evidence/ui-history-20261102/chatgpt-image-generation-capability-review.json)。产品能力说明参考 [OpenAI 图片生成文档](https://learn.chatgpt.com/docs/image-generation)；具体 0.164.0 行为以报告中固定的官方源码为准，不能用当前在线文档替代固定版本证据。
