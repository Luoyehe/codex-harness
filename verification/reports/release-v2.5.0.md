# 长会话续聊、手机交互与视觉附件

> 隐私整理说明：下文的运行与验收结果来自当时发布的原始版本。公开副本移除了私人部署记录；整理后的提交需要独立核验，旧签名和旧发布授权不能沿用。

v2.5.0 汇集对 v2.4.0 的 169 项修复，覆盖 51 个工作包。服务端与网页沿用官方 Codex CLI 0.169.0。

- **长会话**可以从最近消息恢复，核实执行状态后继续发送、压缩、分叉和回退。正文在网页历史中只保留一份。超出完整导出预算时会明确提示。
- **手机端**可在较长的侧栏列表中确认或取消删除会话。浏览、切换视图以及返回聊天保留阅读焦点，点输入框或主动开始编辑时再进入输入。
- **图片与视觉工具**按当前模型能力处理。图片模型直接收图。支持工具的纯文本模型得到文件引用，由模型自行决定是否调用视觉 MCP，沿用已有的工具审批。
- **队列与升级**保留仍被历史或待办使用的附件。旧版重编码的图片会区分原件和队列保存版，来源会话可以下载有依据保留的原图。跨供应商转换分别显示目标会话和所选待办的移交结果。
- **MCP 与恢复**分别展示启动、工具发现与执行状态。手动工具采用当前会话中该服务的实际时限，避免一个慢调用中断其他会话。改进多标签页的操作恢复、部署回退和网络延迟上线后的启动行为。

- **旧配置升级**支持用点号键、内联表或带转义的表头保存的 MCP 开关。迁移保留同文件中其他服务与注释。带 UTF-8 BOM、多行内联表或尾逗号的用户配置也能通过托管启动检查。

- **MCP 设置**只提交实际编辑过的字段。清除环境变量会一并停止转发，修改参数会保留继承的系统开关。已有服务可选择“恢复继承”。
- **自动任务恢复**可在网关重启后向前查找已完成的旧回合。恢复会保留原回执，并允许下一期计划正常启动。工作进程重连后能释放已结束任务占用的名额。停止请求得到明确未送达回执时可重试，送达状态未知时保留记录。
- **审批状态**按会话和回合跟踪。提前到达的审批会出现在任务列表中，最后一项处理后会清除等待提示。长期打开的页面会释放已关闭审批的编号。

- **多客户端供应商设置**保留已选连接与目录草稿。配置刷新后，刚重新勾选的模型能力确认可以正常提交。恢复或删除配置档须根据当前预览确认。

对应实现、逐项验收与平台边界见 [169 项修复与验收报告](https://github.com/Luoyehe/codex-harness/blob/v2.5.0/verification/reports/v240-remediation-acceptance.md)。
