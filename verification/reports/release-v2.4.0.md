本版集中修复三模型交叉审计中确认的问题，并适配 Codex CLI 0.169.0。

- 修复附件引用和会话复制、删除、重启之间的生命周期问题；无法确认的历史保守保留，不推断已删除或自动重放。
- 修复跨供应商会话副本在新 CLI 下的供应商绑定兼容问题；转换仍在独立副本中完成，原会话保持不变。
- 改善操作记录、未知结果恢复、后台任务调度、终端所有权、事件容量和错误隔离，避免局部异常拖垮整个运行时。
- 修复手机布局、设置草稿、分页刷新、对话滚动、录音取消及键盘焦点等交互问题，移除不必要的操作与残余设计。
- 修复 Git 核对及媒体预览首次点击被旧状态清理取消的竞态，保留草稿、旧确认失效、未知回执恢复和媒体资源释放保护。
- 改善模型供应商、MCP、账户用量与权限提示，保留已配置智谱 Coding Plan 的同一 API Key 自动用于四项内置 MCP 服务。
- 完善 HTTPS 首次配置与恢复、代理与部署归档、项目路径及 Git 工作树处理，保留已有账号和控制层边界。
- 扩展测试选择、类型检查、供应链验证、清理和发布核验；修复 Go 安全扫描未实际采集源码的问题，版本发布要求同一主分支提交的测试与安全检查均成功。

升级时在新版源码目录运行 `sh harness.sh`，使用部署工具的升级流程。Root 执行仍需服务器管理员授权，网页开关由用户选择。

验证范围包括定向回归、完整代码审计、隔离环境中的官方 CLI 与本地协议替身。真实付费模型推理、外部 MCP 工具调用、Safari 实机输入法及低端手机性能不在本轮已验证范围内。

发布检查要求最终提交通过 Windows、Linux 普通权限及 Root 全量验证，并按用例身份核对各平台跳过项，拒绝未覆盖或失败的结果。本地完整验证及未通过候选的日志、复现、修复和预防经验均保留在审计证据中。

依赖维护将受影响的 Hono 链更新到维护者公布的修复版本。npm 公告数据库仍对 `@hono/node-server 1.19.19` 报告一条 moderate 提示，与维护者列出的已修复版本存在差异；本项目使用的视觉 MCP 为 stdio 入口，相关离线兼容回归通过。此差异保留在审计记录中，没有将扫描结果描述为零告警。
