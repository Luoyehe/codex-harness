# CLI 能力覆盖核对

本清单按官方 Codex **0.164.0** 新生成协议核对 **178/178** 个 TypeScript 请求，逐项结果在 [capability-coverage.json](capability-coverage.json)。每项关联实际路由、实现、界面、测试源与已有定向证据；不是以字符串或按钮存在判断功能。此项功能核对不计入完整安全审计的清洁轮次，也不能替代全量测试或外部服务验收。

协议包含 175 个 JSON 方法，其中 106 个稳定、69 个实验方法，以及 3 个仅 TypeScript 保留的旧方法。这里按用户工作流判断覆盖，不以字符串出现、按钮存在或任意 RPC 转发作为验收，也不把全部可选字段都视为已支持。

| 方法分类 | 数量 | 判断依据 |
| --- | ---: | --- |
| 网页工作流 | 137 | 实际表单/读取入口接入命名服务路由；具体测试与外部服务限制逐组记录 |
| 受控等价 | 23 | 文件、搜索、配置、Bedrock 等采用更窄的受控路径，差异明确保留 |
| 内部/开发者/旧协议 | 11 | 握手、计数、原始历史注入、实验采样、测试与无 JSON schema 的旧接口 |
| 平台或服务限制 | 7 | 本地硬件验证、Windows 安装与非商业 AWS 分区，未假称支持 |
| 尚无入口的常见工作流缺口 | 0 | 本次发现并分派的入口均已交付；不等于所有平台和外部账号验收完成 |

这不是“完成率”。例如，网页文件操作覆盖了用户需求，但不会开放原生任意路径 `fs/*`；搜索提供有界路径/文本匹配，不保证原生模糊排序；文件监测是当前视图的五秒元数据轮询，不是递归、无丢失的文件事件流。原生账号/供应商资格仍须以真实返回值为准。

## 最后补齐的入口

| 能力 | 已实现与验证边界 |
| --- | --- |
| 下一步建议 | 用户手动请求最新已完成回合，结果归当前连接所有；重新核对后只放入空白草稿，绝不自动发送。运行时与界面定向通过，真实账号生成未执行。资格依原生实际结果。[官方说明](https://learn.chatgpt.com/docs/features/composer-predictions) |
| 额度通知邮件 | 当前账号、通知类型和预览摘要绑定明确确认；展示 `sent` / `cooldown_active`，未知只查原回执。未实际发邮件。[官方协议](https://learn.chatgpt.com/docs/app-server) |
| 已加载会话 | 分页发现、选择后读取、打开和明确停止订阅；不把 `unsubscribed` 描述成进程已卸载或历史已删除 |
| Codex Cloud | 固定 `codex cloud` 官方交互入口，启动前检查共享 ChatGPT 登录，原生身份、全局空闲、受控 PTY；确认退出并送达回执后自动重建后台连接。Windows 与 Linux 跨 UID 的历史无账号错误及清理已验；登录后的浏览、提交和应用未验 |
| Doctor / bundled models | 设置页运行固定命令并读取当前连接私有报告；结果如实显示检查失败。内置模型目录不冒充账号当前目录 |
| Hooks / 全局记忆 | Hooks 仅保留当前连接的有界事件；来源/输出不授予执行权限。全局生成与使用开关采用用户层版本 CAS、差异确认与冲突重读 |

MCP OAuth 登出属于明确的运维 CLI 能力：在受管原生身份及其 HOME/CODEX_HOME 下运行官方 `codex mcp logout <NAME>`，随后重启 app-server 并重新读取状态。隔离无凭据 fixture 与 help 已验证；退出零不等于真实令牌撤销。禁用/删除配置也不等于登出。没有虚构网页 logout RPC。

固定原生 Codex TUI 已提供 `/hooks` 的哈希信任审阅入口，具有全局空闲准入、连接所有权和进程树清理；确认退出后自动重建后台连接，清理无法确认时保留未知状态。无需再造没有官方 RPC 的信任存储。`execpolicy check`、`debug prompt-input`、rollout/NFS 数据迁移保持明确的运维流程；`rollout/compress` 仅证明触发，不能替代迁移或声称压缩已完成。

## 常见 Agent 工作流

覆盖表另列 15 项不与原生方法一一对应的流程：持久计划任务、文件/Git/暂存区恢复、worktree 生命周期、AGENTS.md、技能创建、完整导出、输入模态/引用/输出 schema、审批、父子任务、Hooks CLI、诊断、云任务、OAuth 登出和运维/宿主集成。

目前可追踪到的完整实现包括会话与队列/目标、分支与历史回退、代码审查、项目组织、文件编辑与恢复、暂存/提交/恢复、保留 ignored/dirty 数据的 worktree 归档、技能与插件、MCP 工具/资源/订阅、定时任务、进程、远程执行环境和实时语音本地生命周期。相关 Linux 跨 UID helper 与真实 CLI 证据、以及 mock UI 测试的界限分别记录，互不替代。

Linux 附件定向使用当前测试原文、独立无网络目录和 nobody 身份：**16 通过、0 失败、1 个仅 Windows 适用的测试跳过**。Linux 的 FIFO/符号链接与实际文件权限两项均通过，详见 [attachments-linux.json](attachments-linux.json)。这不是完整媒体跨 UID 验收，也不声称跨平台零跳过。

Linux 跨 UID CLI/诊断另有 **40 项检查通过**：生产固定 launcher、原生 CLI 首屏、关闭/断线、Cloud 无账号错误、Doctor 与 bundled models、私有输出和 UID 清理均在 PrivateNetwork 下验证。生产资源限制为 256 tasks / 3 GiB，观测峰值 112，未触发 pids 上限。详见 [linux-cli-crossuid.json](linux-cli-crossuid.json)。全部工具面板亦已统一返回聊天入口，保留已运行会话与待答表单，相关定向与受控浏览器证据在 JSON 中。

上述功能核对未执行真实 ChatGPT 登录、信用额度消费/邮件、预测、外部语音、AWS、登录后的云任务或远程插件分享；外部账号资格、平台支持与代码入口是不同的验收条件。历史定向报告保留当时源码哈希，不冒充 LF 归一化或其他后续变更后的字节已重新测试。最新快照的全量测试、独立实例部署及发布状态见 [执行记录](../WORKLOG.md) 和 [发布检查](../RELEASE-CHECKS.md)。
