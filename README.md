# Codex Harness

把 OpenAI 开源的 Codex 编程助手装进浏览器：在自己的服务器上跑一个网页控制台，获得完整的 Agent 能力——多项目、多会话、命令审批、沙箱、文件 diff、网页终端，以及自动上下文压缩。

支持三种模型源：**ChatGPT 账号**（官方原生）、**智谱个人版 Coding Plan**（GLM 系列 + 官方四个 MCP 工具）、**任意 OpenAI 兼容 API**（本地 vLLM / 中转站等）。

```
浏览器 ──HTTPS──> Caddy(TLS) ──登录──> Authelia
                     │ 鉴权通过后反代
                     ▼
       Gateway（systemd 服务，只监听本机，token 认证）
                     │ 本机进程通信
                     ▼
             codex app-server（官方开源组件）
                     └─ 会话持久化在服务器，关掉浏览器任务继续跑
```

## 先回答你可能关心的问题

| 问题 | 答案 |
|---|---|
| **什么系统能部署？** | 仅 **Linux 服务器**（推荐 Ubuntu 22.04+ / Debian 12，需要 systemd + root）。Windows 和 macOS 不能作为部署服务器，但可以作为开发机（见文末开发章节）。**任何设备**的浏览器（含手机）都能访问部署好的页面。 |
| **会自动安装 codex 本体吗？** | **会。** 安装脚本会自动安装并锁定经测试兼容的版本（codex 0.149.0、智谱 MCP 组件 0.1.4）、Node 22、pnpm，并完成构建和 systemd 服务注册。你不需要预先准备任何东西。 |
| **需要什么账号？** | 三选一：ChatGPT 账号（页面里设备码登录）/ 智谱 Coding Plan 的 API Key / 一个 OpenAI 兼容端点。安装向导会引导你选择。 |
| **用脚本装完之后还要手动做什么？** | **什么都不用。** 安装脚本完成全部工作，装完浏览器打开就能用。本页其它章节描述的能力（换模型源、远程访问、重启服务等）都已内置在网页的「设置」里，不需要回服务器敲命令。 |
| **这是多用户产品吗？** | **不是。** 单管理员设计：所有登录者共享同一 Codex 账号、会话与终端，彼此可见。适合个人自托管，不要给团队共用（详见安全边界）。 |

## 快速部署（唯一入口）

**你需要做的只有 4 件事：**

1. **准备一台 Linux 服务器**（Ubuntu 22.04+ / Debian 12，root 权限，能联网）
2. **运行一条安装命令**（root 下）：

```bash
curl -fsSL https://raw.githubusercontent.com/Luoyehe/codex-harness/main/deploy/install.sh | bash
```

（也可以 `git clone https://github.com/Luoyehe/codex-harness && cd codex-harness && ./deploy/install.sh`，效果相同。）

3. **回答安装向导的几个问题**：选择模型源（粘贴智谱 Key / 选稍后设备码登录 ChatGPT / 填自定义 API 地址）、选择远程访问方式（见下方表格）。每一步都有默认值，直接回车可跳过（之后都能在网页里改）。
4. **装完后浏览器打开** `http://127.0.0.1:8080`（ChatGPT 模式再点右上角设备码登录一次）。

**脚本替你做的（不用动手）：**

- 安装全部依赖：Node 22、pnpm、codex CLI（锁定兼容版本）、智谱 MCP 组件
- 构建前后端、注册 systemd 服务、设置开机自启并启动
- 生成网关认证 token 与安全配置
- 自动运行完整部署验证（鉴权、WebSocket、终端、模型列表全链路），有失败项会当场提示

**你不需要做的（常见疑虑，逐条排除）：**

- 不需要预先安装任何东西——Node、pnpm、codex 本体全部由脚本自动安装并锁定版本
- 不需要配置 systemd、开机自启、防火墙规则
- 不需要获取、生成或填写任何 token / 证书 / 密钥文件
- 不需要手动验证部署是否成功
- **装完之后不需要任何手动收尾**——换模型源、同步模型、改远程访问、重启服务等所有日常管理都在网页「设置 → 服务器管理」里完成

### 远程访问（安装时二选一，随时可改）

| 方式 | 适合 | 怎么做 |
|---|---|---|
| **仅本机 / SSH 隧道**（默认） | 只有自己用 | 在你的电脑上执行 `ssh -L 8080:127.0.0.1:8080 服务器`，然后浏览器开 `http://127.0.0.1:8080` |
| **HTTPS 域名 + 登录** | 手机/多设备随时访问 | 安装时选择 Caddy + Authelia，回答域名/端口/账号密码即可；证书可自签或用自有证书。之后也可在网页「设置 → 服务器管理 → 远程访问」中配置或修改 |

## 日常使用与管理（都在网页里）

**「设置 → 服务器管理」** 已包含以下全部功能，一步完成、自动重启生效，无需登录服务器：

- 切换模型源（OpenAI / 智谱 / 自定义 API，表单填写即可）
- **一键从上游同步最新模型列表与思考档位**
- 配置/修改远程访问（Caddy + Authelia）
- 重启服务、查看服务日志

**「设置 → 对话」**：控制对话中显示哪些内容（思考/命令/文件修改/MCP/搜索）、自动压缩阈值。

日常对话功能速览：输入框下方可即时切换 模型 / 审批策略 / 沙箱 / 思考档位；命令执行会弹出审批卡片；底部抽屉里有 diff 汇总和网页终端；上下文快满时可手动或自动压缩。

### 什么时候才需要登录服务器？

只有网页完全打不开等极端情况。此时有一个交互式维护菜单：

```bash
bash <安装目录>/deploy/manage.sh    # 安装完成时的输出会给出确切路径；git clone 安装即仓库目录
```

涵盖：切换模型源、配置远程访问、重启、看日志、完整验证、修复重装（保留数据）、检查更新（git 安装方式下可一键拉取新版本并重建）。**这些是备用入口，正常情况下你用不到它们。**

## 安全红线

- ❌ **不要把网关端口直接暴露到公网。** 网关只监听本机，远程访问必须走上面两种方式之一（SSH 隧道或 Caddy+Authelia）。
- ❌ **不要多人共用。** 所有登录者共享同一账号与数据，无用户隔离。
- ❌ **不要手动编辑服务器上的 `~/.codex` 配置和 `/etc/codex-harness.env`。** 模型源、密钥、远程访问全部通过网页或脚本管理，手工改动会与它们互相踩踏（例外：按文档排障时按指引修改）。
- ❌ **不要自己升级 codex CLI 版本。** 协议类型与 codex 版本绑定，擅自升级会不兼容；等本仓库适配后用 `manage.sh update` 一起更新。

---

## 安全边界

- 网关 WebSocket 采用 token 认证（`~/.codex/gateway-token`，600 权限）+ Host 白名单（防 DNS rebinding），仅监听回环地址
- 浏览器只能调用白名单 RPC（文件写入、进程管理等高危接口不对浏览器开放）；沙箱预设由网关映射，页面无法注入任意策略
- 终端以服务用户权限运行，等同 SSH 进服务器——请用 systemd 运行用户和工作目录控制可触达范围
- 排障提示：页面能打开但提示「gateway 未连接」= 反代域名不在网关信任列表，在网页「设置 → 服务器管理 → 远程访问」重新应用一次配置即可（会自动登记域名并重启）

## 从源码开发（Windows / macOS 可）

```bash
npm install -g pnpm @openai/codex   # codex CLI 0.149.x
pnpm install
pnpm dev        # 同时起 gateway(8410) 与 web(5173)
```

打开 `http://127.0.0.1:5173`（Vite 代理会自动完成与网关的认证对接，无需手动拿 token）。

开发期用智谱模型源建议使用项目内沙箱目录避免污染本机配置，详见 [`deploy/README.md`](deploy/README.md)。测试与构建：`pnpm test` / `pnpm typecheck` / `pnpm build`；协议类型 `protocol/` 由 `codex app-server generate-ts` 生成，随仓库提交、与 codex 版本绑定。

推送与 PR 会自动跑 CI（类型检查、单测、构建、部署脚本语法、密钥泄漏审计）。
